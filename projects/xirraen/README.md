# xirraen — personal links

A compact, responsive personal link page for `@xirraen`, styled around the profile's research-led and engineering-focused identity.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run typecheck
npm run lint
npm run build
```
