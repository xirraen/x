# xirraen — Web3 profile

A compact, responsive profile and link page for `@xirraen`, styled around the blue-violet X profile aesthetic and an original Web3 avatar.

## Run locally

```bash
npm install
npm run dev
```

## Build and checks

```bash
npm run typecheck
npm run lint
npm run build
```

## Wallet snapshot

The page displays the public wallet address supplied by the owner and copies it when the address card is tapped or clicked. The checked snapshot showed no native-coin or token balances on Ethereum, Optimism, Arbitrum, Base, Gnosis, Polygon, and Avalanche C-Chain as of 10 October 2026, 15:39 WIB. The percentage chart remains unavailable because there are no detected holdings to chart; the page does not invent zero-percent returns.

The snapshot was checked with public Blockscout explorer pages for six networks and the Routescan keyless read-only API for Avalanche C-Chain. It is a point-in-time check, not a continuous portfolio feed, and other EVM networks are outside this snapshot. No private key, seed phrase, signer, or transaction endpoint is used.
