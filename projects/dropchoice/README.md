# Dropchoice

Evidence-first Web3 opportunity intelligence workspace for discovering signals, evaluating uncertainty, recording evidence, tracking research, and comparing route trade-offs.

## Current status
Local prototype scaffold, not a production service.
- Demo data only; no live source ingestion.
- No authentication or durable backend.
- No wallet connected; no signature requested.
- No transaction can be executed from this prototype.
- Verify official sources independently.

Editorial labels are not financial forecasts or reward guarantees. Surfaces: Home Feed, Opportunities, Action Preview (read-only), Events, My Activity, Safety & Alerts.

Stack: Vite, React, TypeScript, plain CSS. Framework migration requires a separate decision.

Run: `npm install`, `npm run dev`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`.
