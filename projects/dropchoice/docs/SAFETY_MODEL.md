# Safety Model

Prototype disclosures: demo data only; no wallet connected; no signature requested; no transaction execution; verify official sources independently.

Action Preview is read-only. Wallet functionality requires separate scope, threat model, consent, and review.

The current Web Scan is not a live network scanner. Production requires isolated workers, URL canonicalization, DNS/redirect controls, SSRF protections, content-type/size limits, phishing/malware classification, provenance, human review, and privacy/retention policies.

Public chain activity does not prove address ownership. Opportunity labels do not guarantee eligibility, rewards, profitability, or safety.
