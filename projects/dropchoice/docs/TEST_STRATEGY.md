# Test Strategy

Unit: filtering/sorting, evaluation boundaries, critical-risk overrides, evidence freshness, route comparison, task transitions, schema validation.

Integration: navigation, search/filter, dialogs and focus, read-only Action Preview, Web Scan demo makes no network requests, safety warnings, stale-data indicators.

Accessibility: keyboard navigation, semantic labels, focus restoration, reduced motion, contrast, responsive layout.

Security before backend: SSRF, redirects, DNS/URL normalization, type/size limits, authorization, rate limits, XSS, audit logs, secrets, workflow permissions.

Passing a build is not proof of product completeness or security.
