The supplied archive is a static website prototype with an inline HTML/CSS/JavaScript implementation and accompanying whitepaper and technical analysis documents. The archive SHA-256 supplied and verified during extraction is:

## Prototype areas listed in its README
- Dashboard Overview
- Airdrop Intelligence
- Read-only demo Address Scanner
- Demo On-chain Activity timeline
- Participation Tracker
- Saved Research and Settings
- Search projects/chains, bookmarks, and demo wallet interaction
- Responsive desktop, tablet, and mobile layout

## Source caveat
The archive itself describes these features as prototype/demo behavior. It explicitly states that scanner, wallet, activity, airdrop intelligence, and network status do not yet use live blockchain data. It also states that the frontend does not include a backend/database, production wallet authentication, or blockchain/indexer integration.

This note records the source archive's stated scope; it is not a claim that the listed features have been connected to live services in the Next.js migration.
