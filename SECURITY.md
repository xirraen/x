# Security Policy

Report suspected vulnerabilities privately through the repository maintainer's published contact channels. Do not include secrets, private keys, seed phrases, or sensitive personal data.

Rules: never commit secrets; treat URLs/fetched content/user text as untrusted; validate inputs and enforce network resource limits; use least-privilege workflow permissions; keep previews separate from signing/execution; preserve evidence provenance and uncertainty.

Automated checks do not guarantee security. Production ingestion, authentication, and wallet-related capabilities require dedicated threat modeling and review.
